# Custom Agent Rules for OpenAlgo Autonomous Research

- **OpenAlgo SDK Reference**: When writing, debugging, auditing, or modifying strategy bots, or when invoking any OpenAlgo Python SDK operations (including REST API calls and WebSocket streaming), you must always read and refer to the complete, precise reference guide located at [openalgo-sdk-reference.md](file:///root/openalgo-autonomous-research/docs/guides/openalgo-sdk-reference.md). Follow the documented method signatures, `**kwargs` options, and response dictionary shapes exactly.
- **OpenAlgo WebSocket, Architecture, & Broker Compatibility Reference**: When working with, debugging, or auditing WebSocket connections, stream subscriptions, ZeroMQ transport, or broker API compatibility/capabilities, refer to the architectural details and configurations outlined in [README.md](file:///root/openalgo/README.md), [DISCOVERY_MAP.md](file:///root/openalgo/DISCOVERY_MAP.md), [BROKER_API_COMPATIBILITY.md](file:///root/openalgo/audit/BROKER_API_COMPATIBILITY.md), and [WEBSOCKET_README.md](file:///root/openalgo/collections/openalgo/IN_stock/WEBSOCKET_README.md).
- **Active Broker (Angel One) Guidelines**: The active broker is **Angel One** (`angel`). Ensure all strategy bots, order execution settings, and API configurations are compatible with the Angel One plugin. Keep in mind that Angel One supports standard 5-level market depth streaming and live margin calculations, but the `get_intervals` method is not supported (historical data `/api/v1/history` is supported). Supported exchanges include NSE, BSE, NFO, BFO, CDS, MCX, and indices.
